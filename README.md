Nous本体与插件版本记录独立。开发者通过应用内提交商城审核，GitHub保存发行文件与对应源码；本地安装固定标为非官方。协议1.3由宿主明确列出兼容版本后才允许安装。

Windows仅安装版，Android ARM64应用名Nous。客户端必须登录，网页版游客仅使用能力与成本。公告只投递已登录普通用户。SDK与示例MIT，插件依各自及上游许可证。
