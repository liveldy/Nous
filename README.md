# Nous

Nous 官方门户与客户端发布仓库。此仓库仅包含门户、说明文档、插件协议及签名版本清单；**不包含 Nous 主程序源码**。

- [网页版（原 IP）](http://110.42.63.153:7783)
- [插件开发文档](docs/plugin-development.md)
- [版本与分发说明](docs/version-management.md)
- [全能下载器独立仓库](https://github.com/liveldy/Nous-Plugin-YunX)

Windows x64 仅安装版；Android ARM64 应用名 Nous。客户端必须登录，网页版游客仅可使用能力与成本。所有客户端和插件发行文件托管于 GitHub，服务器不保存分发包。

Nous 的正式版本起点为 1.0.0；1.0.4 完善通用网页登录会话校验，沿用应用标识、Android 签名和用户数据。升级前保存文件。客户端自行校验签名版本清单与安装包 SHA-256。
