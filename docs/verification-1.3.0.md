# Nous 1.3.0

- API监视改为同一张每日用量折线图及接口列表，各接口请求数与Token分别着色，支持缩放、平移、图例筛选和全屏。
- 修复海外接口自动检测和参数缓存：检测沿用客户端网络通道，设备与网页缓存隔离，切换页面及重启后保留有效元数据。
- 新增Devin运营商，按官方v3接口只读查询身份、会话可访问性与ACU用量，不自动创建任务或把ACU换算成Token。
- 开发、写作与助手支持安装SKILL.md、技能目录及ZIP；斜杠按需调用，助手可配置默认技能，设置入口统一命名为“技能”。
- 模型排行榜新增独立运营商/CEO与国家旗帜列，国家名称在悬停或获得焦点时显示；能力与成本图中的“支配”改为“斩杀”。
- 移动端保留四个核心入口及“更多”，扩展模块在更多列表中排列；精简重复说明与辅助标签。

验证：完整Go测试、28项Node检查、真实浏览器与Electron流程、Devin/Grok只读自动检测、技能实际注入及本机开发代理执行、移动端布局、Android策略测试、构建/lint/签名校验、Windows安装包与程序图标一致性及快捷方式四种组合。未进行Android实机测试。每日图表仅统计升级后Nous记录的已完成调用，旧版本缺失的每日数据不补造。

Windows仅安装版，Android名称Nous。公开插件接口仍为1.3，SDK仍为1.3.0；主程序源码不上传，发行文件仅在GitHub。
