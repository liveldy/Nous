Nous 1.1.0 · 公开插件协议与SDK

公开Plugin Interface1.2和独立SDK1.2.0，包含脚手架、预览、静态检查、Schema/类型、打包、目录提交工具、离线手册及独立UI和JVM/Dex示例。无需了解主程序或下载器内部代码。客户端本机开发模式支持回环开发服务器和原生模块测试，Android可通过adb reverse连接。

安装和打开前明确协商api/supportedApis，检查最低宿主版本、平台、权限及必需方法；当前明确兼容1.0、1.1、1.2，未知协议、过低宿主或缺少必需方法均拒绝安装。宿主按本机版本提供能力，提供参数校验、结构化错误、请求大小/并发限制、超时与取消等待。

通用内置登录按平台选择URL与UA，Android使用原生移动UA和手机宽度；API校验UA与网页登录分开。提供双端默认浏览器OAuth授权码+PKCE自动回传接口。当前下载器Cookie供应商没有经过验证的外部自动授权通道，按要求隐藏外部登录；不以仅打开浏览器或手动复制冒充自动回传。

全能下载器改名破晓下载器（DawnDownloader）1.2.0，保留插件ID和本机数据，独立公开对应源码并复用1.1.5不可变运行模块。宿主仅增加通用协议能力。Windows NSIS安装包明确使用Nous图标，实际EXE图标与程序一致。

验证：32项Node测试；真实Electron插件安装/导航/登录夹具及独立原生示例；Android API35/Robolectric四项回归（移动WebView配置、协议门禁、账户数据隔离、本机开发安装/停用）；实际Java PKCE回环状态绑定与一次性交付；生产构建、Android lint和APK签名；1440/768/390界面检查。没有Android实机或真实供应商账户的端到端验证。

Windows仅安装版；Android名Nous，沿用签名和数据。主仓库仅公开门户、文档、SDK及签名目录，不上传主程序源码。所有发行文件均在GitHub，原IP服务器仅提供网站和接口。
