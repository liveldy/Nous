# 模型模态

能力与成本、API接口详情、开发、写作、助手与图片/视频配置共用同一套模态标注。模型选择项与当前型号旁都显示能力；搜索能力与成本时也可输入“视觉”“文生图”等词。

| 标注 | 含义 |
| --- | --- |
| 文字 | 接收或输出文本 |
| 图形-视觉 | 接收并理解图像 |
| 图形-文生图 / 图形-图生图 | 按文字生成图像 / 基于图像生成图像 |
| 视频-理解 | 接收并理解视频 |
| 视频-文生视频 / 视频-图生视频 / 视频-编辑 | 生成或编辑视频 |
| 音频-理解 / 音频-识别 | 理解音频 / 识别音频类别 |
| 音频-人声-识别 / 音频-人声-合成 | 语音转文字 / 合成语音 |
| 音频-合成 | 生成音频，来源未限定为人声 |
| 文档-理解 | 接收文档或文件 |
| 向量-嵌入 / 文字-重排 | 生成嵌入向量 / 重排文本 |

优先读取接口返回的输入、输出模态与任务类型，再补充公开目录中同型号的元数据。只有无方向的旧数据时，显示“图形-未注明方向”等；来源没有发布时显示“模态未公开”。不会因为一个聊天模型支持视觉，就宣称它可以生成图片或视频。

文字协作默认选择能接收并输出文字的型号。已经明确不适合当前位置的专用型号保留其模态但不可选；未公开能力的型号和手动填写继续允许尝试，由接口返回实际结果。图片、视频配置分别匹配相应输出模态。
