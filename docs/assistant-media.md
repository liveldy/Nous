# 助手媒体

1.3.2助手头像使用用户提供的14个模型家族头像，按所选型号自动匹配。头像资源与原有情绪贴纸分开存放，聊天头部、侧栏与消息使用一致的头像。

聊天模型与接口在创建后保持固定。在助手配置的“图片与视频”中，可分别启用图片、视频生成，并选择当前账户自己的接口与对应生成模型。聊天模型不等于生成模型；例如 Grok 聊天模型通过工具调用独立的 Imagine 图像或视频模型。

图片支持 OpenAI 兼容 `/images/generations`（base64或图片URL返回）以及 Gemini `generateContent` 的图片返回。视频支持 xAI 兼容 `/videos/generations` 和 `/videos/{request_id}`。可手动填写生成模型ID，不能保证供应商的普通聊天模型列表包含所有媒体模型。未配置对应接口时，不提供该生成工具。调用按供应商实际规则计费。

视频只提交一次，记录任务ID并在后台轮询；排队、完成、失败分别展示。重新打开对话或重启服务后可继续查询已有任务，不会自动重新发起收费生成。每轮后台跟踪最多十分钟，未完成任务超过十五分钟不再等待；已经生成的结果仍可下载。删除对话会取消本应用后续查询，不代表供应商撤销已经接受的收费任务。

生成结果保存为所属账户的附件，单个媒体上限32MB，并受账户64MB云空间额度限制。媒体URL不携带API认证头；原生端的生成、轮询和媒体下载继续通过当前设备的加密中继，设备离线时不会回退服务器出口。

支持Range的媒体服务器按512KB分段下载，中断时只重试当前分段，每段最多三次；校验分段位置、总长度和文件版本，成功后才保存附件。没有Range支持时兼容完整下载。下载中断、文件超限与云空间不足分别报告，取消请求会释放对应本机中继任务。下载重试只获取既有结果，不重新提交生成任务。

语音消息使用聊天气泡，包含播放/暂停、秒数和可折叠的语音文字；只会同时播放一条语音。时长优先从媒体文件读取，录音时长同时随附件保存。旧音频在元数据尚不可用时不编造秒数。录音提供计时、取消及结束；录音过程中不能发送消息。录音入口继续遵循所选聊天模型的音频输入能力。

协议依据：[xAI图片生成](https://docs.x.ai/developers/model-capabilities/images/generation)、[xAI视频接口](https://docs.x.ai/developers/rest-api-reference/inference/videos)。
