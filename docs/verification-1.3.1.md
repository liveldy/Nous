# Nous 1.3.1

- 程序更新、插件和文件下载显示真实进度，补齐Windows更新状态。
- 插件发行包先由客户端预取或选择本地文件，再上传作内存校验，减少服务器连接GitHub造成的提交失败；顶级管理员可以直接发布。
- 管理员可删除商城插件，保留审核历史和用户已安装数据。
- 删除与Windows本机工具、命令、开发代理授权统一使用应用内确认，保留账户校验与超时拒绝。
- 语音消息改为聊天气泡，支持播放、暂停和秒数；录音显示计时并可取消。
- 助手可分别配置图片、视频生成接口与模型；视频后台持续查询并自动显示结果，原生设备离线不回退服务器。
- 注册与找回密码使用独立邮件模板，新验证码绑定用途；精简重复辅助文案。

Windows仅提供NSIS安装版；Android ARM64应用名Nous，版本码1003001，沿用既有签名和应用标识。插件接口1.3 / SDK1.3.0保持不变；主程序源码不公开。

验证：32项Node/SDK检查、完整Go测试、Chrome三种宽度及Electron交互、Windows打包源码与网页摘要/图标/四种快捷方式组合、Android构建/lint/单元测试/签名一致性检查通过。没有Android实机验证；图片/视频与邮件使用隔离测试接口，未声明真实供应商付费生成或公网SMTP全链路通过。图片/视频需配置相应生成模型。
