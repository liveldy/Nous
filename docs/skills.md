# 技能

支持 [Agent Skills](https://agentskills.io/specification) 的 SKILL.md、目录和 ZIP。安装入口位于设置的“技能”，以及开发、写作、助手的输入框旁。安装后随账号保存，三个模块共用已安装列表。

```markdown
---
name: review-writing
description: Review a document for clarity and factual consistency.
---
检查当前文档，指出含糊、重复和缺少依据的内容。遵循本轮文档编辑权限。
必要时参考 references/style.md。
```

开发与写作仅在当前消息含 `/review-writing` 时加载。输入 `/` 可选择已安装技能。助手也支持斜杠调用；助手配置中的默认技能在该助手的普通消息和主动消息中生效。其他助手不会继承这组默认选择。

安装不会执行脚本。执行工具、修改文件和系统访问仍受当前项目和助手权限约束。本机及云端开发代理会把本轮所选技能的文件放在项目的 `.nous/skills/技能名称/`，并获得该路径；引用、脚本和资源保留原相对目录。写作、助手以及网页或 Android 本地开发会收到技能正文和有大小限制的文本资源；不支持的进程执行能力不会因安装技能而新增。

一个技能最多128个文件、8MB，SKILL.md 最大128KB，名称使用小写字母、数字、连字符，说明最多1024字符。ZIP 必须包含一个 SKILL.md；路径越界、符号链接及重复名称会被拒绝。最多安装80个技能并受账号总存储额度限制；每轮最多选择8个。卸载后不再加载该技能，既有对话、文档和项目中的历史文件保留。

默认启用不代表提升权限。请审阅技能内容和脚本，只安装信任的技能。包含代码执行要求的技能仍需要可用的执行工具与对应授权。
