# Nous 1.2.0

- 新增管理模块：用户管理、插件审批、邮件模板、服务开关与公告。顶级管理员唯一，只有顶级管理员可以任免普通管理员。
- 插件管理增加商城、站内提交审核、本地安装及保留/清除数据卸载；官方标签由管理员维护，本地安装固定为非官方。
- 升级公开Plugin Interface1.3与SDK1.3.0，增加作者及独立历史元信息，保持已声明旧协议的兼容检查。
- 本体历史记录整理为宿主功能变化，各插件拥有自己的版本记录；原生应用不再显示客户端下载区。
- 公告仅投递给已登录的普通用户；管理员只在服务与公告中查看，停服期间管理员仍可访问。
- Windows安装向导可独立选择桌面和开始菜单快捷方式，并记住选择。

验证：28项Node检查、完整Go测试、Android API35/Robolectric五项测试、真实Electron及浏览器流程、实际站内提交、Android构建/lint/签名、Windows NSIS四种快捷方式组合与真实安装向导检查。未进行Android实机测试。

现有账户与数据沿用，Windows仅安装版，Android名称Nous。发行文件仅在GitHub；门户仓库仅含公开文档、SDK及元数据，不含主程序源码。
