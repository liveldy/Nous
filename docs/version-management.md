# 版本与分发

Nous本体和每个插件分别维护产品版本及版本记录。本体releases.json只记宿主功能；插件manifest.changelog记录自身变化，并在插件管理中查看。历史本体记录中混入的插件业务更新已归入对应插件历史；历史安装文件保持原字节、摘要及发布日期。

Nous1.3.1继续提供Plugin Interface1.3 / SDK1.3.0。宿主明确兼容1.0、1.1、1.2、1.3；安装与打开时检查协议列表、最低宿主、平台、权限及必需方法。不能凭同为1.x推测兼容。本地安装在原生层执行同样检查，拒绝降级和不兼容包。

插件商城与审核记录由应用服务器保存元数据；开发者通过Nous站内提交，不再通过GitHub Issue或PR接入商城。旧签名插件目录仅保留为迁移存档，不作为商城失败回退。官方标签由管理员设置，本地和开发安装固定为非官方。

本体版本清单继续使用RSA SHA-256 PKCS#1 v1.5签名信封，客户端下载并验证安装包摘要。Windows仅提供NSIS安装版，安装向导可独立选择桌面/开始菜单快捷方式并记住选择；Android应用名Nous，沿用签名及应用标识。

主仓库仅存门户、公开SDK、文档与元数据，不上传主程序源码。各插件使用独立仓库，按上游许可提供对应源码。全部程序、模块、页面包及源码归档均在GitHub Release；服务器仅保存应用数据及管理元数据，不保存发行包。原IP提供网站与接口，旧下载路径跳转GitHub。
