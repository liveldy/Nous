# 管理

管理员在最左侧栏“助手”下方看到“管理”，二级菜单依次为插件管理、用户管理、SMTP服务、服务与公告。

现有Nars账户在升级时成为唯一顶级管理员，身份绑定账户ID。顶级管理员不能被任免、停用或删除；只有顶级管理员能任免普通管理员。普通管理员管理普通用户，不能通过编辑、停用或删除绕过管理员任免限制。

用户管理支持搜索、资料修改、密码重置、停用/启用和确认删除。保存账户修改会撤销该用户的旧登录会话。

开发者登录后从插件管理的“开发插件”提交GitHub发行包URL与SHA-256。管理员重新校验后批准或驳回；批准后可上架/下架、标记官方/非官方。作者由插件manifest声明，官方标签由审核记录决定。本地安装和开发安装始终为非官方。既有目录迁移记录会注明迁移来源，官方标签初始不自动授予。

SMTP服务编辑验证码邮件的主题与正文，正文保留{{code}}，可使用{{minutes}}和{{appName}}。连接凭证继续保存在服务器配置中，不通过页面返回。预览不发送邮件。

服务开关对普通用户及游客生效，管理员可以在停服期间登录、管理和恢复。公告支持草稿、发布、修改与删除，只有已登录的非管理员普通用户收到公告；管理员在本页面查看管理记录，游客不接收。公告为站内通知，不自动发送邮件。
