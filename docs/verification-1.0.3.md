Nous 1.0.3 · 登录会话校验修复

修复通用网页登录在初始Cookie出现时过早关闭的问题：收集声明域内含路径限制的Cookie、支持插件指定浏览器标识，Cookie稳定后执行插件声明的HTTPS/JSON会话就绪校验。校验未通过时保留官方登录窗口，成功后再返回凭证并清理会话。宿主不包含网盘业务地址或账号保存逻辑。

全能下载器独立更新至1.1.4，修复目录与文件大小映射、夸克分页和指定子目录、Windows抖音浏览器初始化、百度令牌缓存和账户切换状态。下载器业务仍在独立插件仓库维护。

验证：20项自动检查；实际Electron窗口在errno=-6和缺少会话令牌时保持，HTTP-only/路径Cookie及指定UA完整，通过校验后才关闭；真实Windows样例解析与目录往返；最终Java17模块及真实Android仓库字节码分页回归；下载暂停/恢复/文件SHA256；Android宿主与插件构建/lint，APK签名校验。没有Android实机或真实百度账户端到端登录验证。

Windows仅发行安装版，Android应用名称Nous。主程序源码不上传门户仓库，插件对应源码独立公开；全部分发文件位于GitHub，服务器不保存客户端或插件分发文件。
